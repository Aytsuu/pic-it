## Phase 0: Scaffold and Config

**From:** Cursor Agent (Claude Sonnet 4.6)
**To:** Plan Executor

---

### Objective

Bootstrap the Pic It repository into a runnable Expo application with the correct folder structure, TypeScript configuration, linting, environment wiring, and Supabase client in place. Every subsequent phase depends on this base being clean and error-free before any feature work starts.

---

### Scope

- Expo SDK 55 project initialisation using the default template
- `src/` directory structure matching the framework context in `context-factory/frameworks/react-native/`
- TypeScript strict mode with `@/*` path aliases pointing to `src/`
- Full dependency install for all packages used across all phases
- Supabase JS client wired to environment variables
- Root layout and 404 route shells only — no feature screens, no auth, no navigation logic

Out of scope for this phase: authentication, navigation groups, screens, database schema, any Supabase table creation.

---

### Prerequisites

- Node.js and `npm` / `pnpm` available in the shell
- Expo CLI available (`npm install -g expo-cli` or use `npx expo`)
- A Supabase project created and the project URL + anon key copied from the Supabase dashboard (Settings → API)
- Git repository initialised at `D:/pic-it` (already confirmed)

---

### Instructions

Complete every task in order. Tick each checkbox as you finish it.

#### 1. Initialise the Expo app

- [x] Run `npx create-expo-app@latest pic-it --template default` (SDK 55 default template)
- [x] Move the generated `app/` directory into `src/app/` if the template did not place it there; confirm the `src/` tree exists with at minimum `src/app/`

#### 2. Configure TypeScript

- [x] Update `tsconfig.json` in the project root:
  ```json
  {
    "extends": "expo/tsconfig.base",
    "compilerOptions": {
      "strict": true,
      "baseUrl": ".",
      "paths": { "@/*": ["./src/*"] }
    }
  }
  ```

#### 3. Create the folder skeleton

- [x] Create the following directories (add an empty `.gitkeep` in each so they are tracked by git):
  ```text
  src/screens/
  src/components/
  src/hooks/
  src/lib/
  src/utils/
  ```

#### 4. Install all dependencies

- [x] Run the following install commands from the project root:
  ```sh
  npx expo install @supabase/supabase-js @tanstack/react-query
  npx expo install expo-camera expo-media-library expo-sqlite
  npx expo install expo-secure-store expo-constants
  npx expo install @react-native-community/netinfo
  npm install react-native-share
  ```

#### 5. Create the Supabase client

- [x] Create `src/lib/supabase.ts`:
  ```ts
  import { createClient } from '@supabase/supabase-js';

  export const supabase = createClient(
    process.env.EXPO_PUBLIC_SUPABASE_URL!,
    process.env.EXPO_PUBLIC_SUPABASE_ANON_KEY!
  );
  ```

#### 6. Set up environment variables

- [x] Create `.env.local` in the project root and populate both values from the Supabase dashboard:
  ```
  EXPO_PUBLIC_SUPABASE_URL=
  EXPO_PUBLIC_SUPABASE_ANON_KEY=
  ```
- [x] Confirm `.env.local` is listed in `.gitignore` (it must never be committed)
- [x] Create `.env.example` in the project root with both keys present but blank (commit this file):
  ```
  EXPO_PUBLIC_SUPABASE_URL=
  EXPO_PUBLIC_SUPABASE_ANON_KEY=
  ```

#### 7. Write the root layout and 404 shells

- [x] Write `src/app/_layout.tsx` — wraps the app in `QueryClientProvider` and renders `<Slot />`:
  ```tsx
  import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
  import { Slot } from 'expo-router';

  const queryClient = new QueryClient();

  export default function RootLayout() {
    return (
      <QueryClientProvider client={queryClient}>
        <Slot />
      </QueryClientProvider>
    );
  }
  ```
- [x] Write `src/app/+not-found.tsx` — minimal "Page not found" screen:
  ```tsx
  import { Text, View } from 'react-native';

  export default function NotFound() {
    return (
      <View style={{ flex: 1, alignItems: 'center', justifyContent: 'center' }}>
        <Text>Page not found.</Text>
      </View>
    );
  }
  ```

#### 8. Smoke-test the dev server

- [x] Run `npx expo start` and confirm no errors appear in the Metro bundler log
