# Context Factory

Reusable, source-backed framework packs for agents. Each folder under `frameworks/` is a self-contained briefing: architecture, file layout, organization, performance, and conventions.

Load a pack **before** scaffolding, reviewing, or expanding a project of that stack. Prefer these files over generic training data when they conflict.

| Pack | Path | Default stack |
|------|------|---------------|
| React Native (Expo) | [frameworks/react-native](./frameworks/react-native) | Expo SDK 54+, Expo Router, TypeScript strict, New Architecture |

## How to use

1. Open the pack `README.md`.
2. Load the files listed for the task (architecture + folder structure for new work; performance + gotchas for lag or review).
3. Treat **defaults** as constraints unless the product already chose a documented alternative.
